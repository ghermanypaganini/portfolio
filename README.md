# 📦 Portfolio — ghermany.me

This repository is the source code for my personal portfolio, live at [ghermany.me](https://ghermany.me).

Built with:

- Next.js 13
- Next.js App Router
- Next.js Server Actions
- Client & Server Components
- TypeScript
- Tailwind CSS
- Context API
- Framer Motion
- React.Email & Resend
- Light & Dark mode

## Getting started

### Prerequisites

- Node.js >= 24
- A [Resend](https://resend.com) account and API key (used to send emails from the contact form)

### Setup

1. Clone the repository and install dependencies:

   ```bash
   git clone https://github.com/ghermanypaganini/portfolio.git
   cd portfolio
   npm install
   ```

2. Create a `.env.local` file in the project root with your Resend API key:

   ```bash
   RESEND_API_KEY=your_resend_api_key
   ```

3. Run the development server:

   ```bash
   npm run dev
   ```

   The site will be available at [http://localhost:3000](http://localhost:3000).

### Other scripts

| Command         | Description                            |
| --------------- | --------------------------------------- |
| `npm run build` | Builds the app for production           |
| `npm run start` | Runs the built app in production mode   |
| `npm run lint`  | Lints the codebase                      |

## Environment variables

| Variable         | Required | Description                                                                                                    |
| ----------------- | -------- | ---------------------------------------------------------------------------------------------------------------- |
| `RESEND_API_KEY`  | Yes      | API key from [Resend](https://resend.com), used by the contact form (`actions/sendEmail.ts`) to send emails. |
